# docs — 项目文档索引

| 路径 | 内容 |
|---|---|
| `HANDOFF.md` | **入口文档**：项目全貌、架构、关键路径、运行服务、协作纪律。新接手先读这里 |
| `reports/` | 正式审计报告：`favor-turnover-audit.md`（商人青睐配方·流通分覆盖核验）、`consumables-turnover-audit.md`（消耗品配方·流通分核验） |
| `archive/` | 一次性分析产物归档（源页面、解码数据、审计快照、临时脚本），见 `archive/README.md`；全部 `.tmp-*`，git 已忽略 |

## 说明

- 根目录 `README.md` / `CHANGELOG.md` / `CONTRIBUTING.md` / `SECURITY.md` 按 GitHub 仓库惯例保留在根目录（README 需在根目录才会在仓库首页渲染，且其内部链接基于根目录相对路径）。
- 运行时日志在 `logs/`（`logs/archive/` 为历史归档），不属于文档体系。
